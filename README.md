# The Cozy Cup

## Project Overview
A simple, responsive one-page website for a café called The Cozy Cup. It shows the café's specials, menu, and contact details. Target audience: students and young professionals looking for a cozy place for coffee and snacks.

Live website: https://simon2026-max.github.io/cafe-website/

## Features
- Responsive design that works on desktop and mobile
- Mobile hamburger navigation menu
- Carousel for today's specials
- Interactive "Order Now" button
- Menu cards and contact section

## Technology Stack
- HTML
- CSS
- JavaScript

## Setup Instructions
1. Clone this repository or download it as a ZIP.
2. Open the folder and double-click `index.html` to view the site in your browser.
3. No installation is needed.
